# 一、提示词包 30 条（可直接复制）

> 用法：把【】里的内容换成你自己的，其余一字不改直接粘进 WorkBuddy。
> 建议：用顺手的那几条存成"收藏"，后面每天用。

## A 类 · 装库（8 条）——让 AI 认识你的产品

**A1 帮我梳理该装什么**
```
我是【行业】的【岗位】，主要卖【产品/服务】，客户是【客户类型】。
请列出我该给你准备的资料清单，按重要性排序，最多 10 项，每项说明"为什么需要"。
```

**A2 把散资料整理成标准卡片**
```
以下是我的产品资料（粘贴原文）。请整理成标准卡片，每个字段一行：
产品名 / 一句话卖点 / 适用人群 / 不适用人群 / 规格与价格 / 核心差异点 / 常见疑问。
缺的字段请标"待补"。
```

**A3 从聊天记录里挖高频问题**
```
以下是我和客户的聊天片段（粘贴）。请提取客户问得最多的 10 个问题，
按频率排序，每个问题附一句"我们实际是怎么回答的"。
```

**A4 把好评整理成客户见证**
```
以下是客户给我的好评（粘贴）。请整理成 5 条可对外使用的客户见证，
每条包含：客户身份（脱敏）/ 原来的问题 / 用了之后的变化 / 一句原话引用。
```

**A5 提取我自己的说话风格**
```
以下是我自己发的 20 条消息（粘贴）。请总结我的说话风格：
句子长短、常用词、口头禅、语气（温和/直接）、是否用表情。
以后帮我写话术时请模仿这个风格。
```

**A6 验证答得准不准（装完必做）**
```
我要验证你是否真的了解我的产品。请只根据我提供的资料回答，不知道就说"资料里没有"。
问题1：……（问价格政策）
问题2：……（问效果边界）
问题3：……（问和其他家的区别）
问题4：……（问售后）
问题5：……（问最不适合谁用）
```

**A7 让它自己说缺什么**
```
刚才第【N】题你答错了。请分析：是资料缺失，还是你理解错了？
如果是资料缺失，请告诉我具体缺哪一份、应该包含哪些字段。
```

**A8 月度查过期**
```
请检查我的知识库里哪些内容可能已过期（价格、活动、规格、政策），
列出可疑项并说明理由，我逐条确认后更新。
```

## B 类 · 派活（8 条）——让它每天给你派单

**B1 今日跟进清单（核心，每天用）**
```
我是【岗位】，今天要跟进一批客户。规则：
1) 到期前【N】天的客户 → 催续/提醒
2) 超过【N】天没互动的客户 → 关怀+约
3) 体验/试用后【N】天没下文 → 跟进
客户信息如下（一行一个：姓名/状态/上次接触/备注）：
【粘贴名单】
请输出今日跟进清单，按优先级排序，每人给：优先级 / 一句话理由 / 一条开场话术（3 行内）。
名单控制在【5-8】人，超出的告诉我"今天先做这些，其余顺延"。
```

**B2 给客户分层打标**
```
以下是我们的客户名单和基本信息（粘贴）。请按【活跃度/意向度/价值】三个维度给每个客户打标
（高/中/低），并说明判断依据。输出成表格。
```

**B3 到期/续费预警名单**
```
以下是客户名单，包含【购买日期/到期日期/使用频次】（粘贴）。
请列出未来【30】天内到期的客户，按"到期日先后 + 使用频次高低"排序，
标出哪些是"用得勤该续"、哪些是"用得少要先激活"。
```

**B4 流失预警名单**
```
以下是客户最近到店/互动记录（粘贴）。请找出超过【21】天没有任何互动的客户，
按"上次价值高低"排序，并给每人一句"重新搭话的开场"（不要推销，先关心）。
```

**B5 按客户出开场话术**
```
客户【姓名】，情况：【购买了什么/上次聊到哪/他的关注点】。
请给我 3 条不同的开场话术：一条关心型、一条价值型、一条轻邀约型。每条不超过 2 行。
```

**B6 今天只做最重要的 5 个**
```
这是我今天的所有待跟进客户（粘贴）。请帮我判断哪 5 个最值得今天跟，
标准是"成交可能性 × 时间紧迫度"，并告诉我另外那些为什么可以往后放。
```

**B7 每日一句提醒**
```
根据我今天的清单和最近的成交情况，给我一句 20 字以内的提醒，
让我今天别犯最常见的错（比如：别一上来就报价）。
```

**B8 把月度目标拆成本周动作**
```
我这个月要完成【目标，如成交 8 单/续费 10 个】。目前进度【已完成多少】。
请把剩下的拆到本周，告诉我每天要跟进几个客户、做什么动作，越具体越好。
```

## C 类 · 应答（8 条）——客户一句话，给你三条回复

**C1 客户消息 → 回复草稿（核心）**
```
客户发来这句话：【粘贴原话】
背景：他是【客户类型/阶段】，我们在卖【产品】，价格区间【】。
请给我 3 条可直接发送的回复，风格：【按我的说话风格，见 A5 的设置】。
要求：每条 3 行内；不要用"亲""呢"；最后带一个动作钩子（约时间/看资料/给反馈）。
注意：不承诺效果、不擅自报价，涉及价格就提示我"要问老板"。
```

**C2 异议：太贵了**
```
客户说"太贵了"。请先判断他属于哪种情况：【真买不起 / 比价 / 试探 / 价值没感受到】。
按不同情况给我对应的回复思路，每种给 1 条示范。核心原则：先问目标，不先降价。
```

**C3 异议：用了没效果怎么办**
```
客户担心"用了没效果"。请给我回复，要求：
先共情 → 给具体证据（案例/原理）→ 给兜底方案（不承诺效果，但说明服务边界）。
3 行内，不要长篇大论。
```

**C4 异议：我再考虑考虑**
```
客户说"再考虑考虑"。请给我 3 条回复：一条问清真实顾虑、一条给决策理由、一条以退为进。
不要逼单，目标是把"考虑"变成"说清楚在考虑什么"。
```

**C5 异议：要和家人/合伙人商量**
```
客户说"要和我老公/合伙人商量"。请给我回复，目标有两个：
1) 判断这是真话还是借口；2) 如果是真的，帮我准备一份"给他看的一页说明"。
```

**C6 用我自己的话改写**
```
下面这条话术太像 AI 写的，请按我的说话风格重写，意思不变、更口语、更短：
【粘贴话术】
```

**C7 给我三档语气的备选**
```
针对下面这个场景【描述】，请给三条回复：一条偏温和、一条偏直接、一条偏专业。
我要根据客户性格选一条发。
```

**C8 复盘这段对话**
```
以下是我和客户的完整对话（粘贴）。请分析：
1) 哪一句之后客户态度变冷了？2) 我当时应该怎么说？3) 这段对话客户真正的顾虑是什么？
```

## D 类 · 复盘（6 条）——一周的活十分钟算明白

**D1 周复盘（核心，每周用）**
```
这是我本周的跟进记录（粘贴：跟了谁/聊了什么/结果如何）。
请出一页复盘：① 本周跟了多少人、回了多少、成了几单（三个数）
② 转化率是多少 ③ 最漏的是哪一环（加微→深聊→方案→成交，指出卡最狠的那个）
④ 下周只改一件事，改什么、怎么改。
```

**D2 漏斗算账**
```
我这周的数据：接触【】人 / 深聊【】人 / 出方案【】人 / 成交【】单。
请画出漏斗，算出每一层的转化率，并告诉我哪一层低于正常水平。
```

**D3 找最漏一环**
```
我的漏斗是【粘贴上一步结果】。请判断：如果只补一层，补哪一层的收益最大？为什么？
给出 3 个具体动作。
```

**D4 下周只改一处**
```
根据上面的分析，请给我 3 个候选改进方案（只改一个动作/一句话术/一个时间点），
按"见效快慢"排序，并说明怎么验证它有没有用。
```

**D5 总结客户画像**
```
以下是我最近成交的 5 个客户信息（粘贴）。请总结他们的共同点：
行业/规模/最在意什么/决策习惯/成交触发点。我要用它来找下一批客户。
```

**D6 月度总结给老板**
```
这是我这个月的数据和主要动作（粘贴）。请写一页月度总结给老板，包含：
做了哪些动作 / 数据变化 / 最大的一个发现 / 下月计划。语气务实，不要形容词堆砌。
```
