# 美业门店 AI 升级交付方案 V1（瑜伽馆样板）

> 定位：给**一家门店**做 AI 升级交付的完整方案（内部主方案；对外谈单可裁剪成提案）
> 依据：交付 SOP v0.1 评审修订 + FDE 七步 + 数字员工矩阵 + 企微能力边界（官方核实）
> 版本：v1.0（2026-11-04）｜ 样板行业：瑜伽馆（美容院/私教工作室通用）

---

## 一、方案总览（一页看懂）

| 项 | 内容 |
|---|---|
| 给老板的一句话 | 不装问答机器人，装一个**每天主动派单、自带战报**的作战系统 |
| 交付物 | **门店专属 AI 工作台**：客户档案库 + 销冠话术库 + 每日作战清单 + 价值周报 |
| 交付周期 | 3 周交付 + 30 天陪跑 |
| 交付团队 | **首店四人组**（样板配置）：宝总（商务拍板）/ 佳瞳（诊断+陪跑）/ 吴松海（搭建）/ 蓝蓝（语料+手册+验收） |
| 收费 | 诊断费前置 + 样板交付费 + 效果月费（与结果挂钩） |
| 三条铁律 | ①AI 只出草稿，绝不直接发客户 ②员工每天只做三件事：看清单、发话术、标结果 ③吐槽 48 小时内修 |

**为什么不是问答机器人（对老板口径）**：被动（员工不问就死）/ 通用（不认识具体客户）/ 无闭环（说不出帮你赚了多少钱）。

---

## 二、首店定位：样板单（先说清钱怎么算）

- **首店 = 样板战略单**：收费打折，换三样——老板深度配合（每周复盘必到）、案例署名权、同行参访接待权。挣的是案例和可复制资产，不是这一单的利润。
- **正价线**：连锁 2 家以上 / 多店品牌 / 私域卖货企业，走 5-20 万正价交付。
- **首店选店标准（五条）**：
  1. 会员 ≥300 人（数据地基太薄不接）
  2. 收银系统能导出 Excel（烂没关系，导不出不接）
  3. 客户沟通在**企微**（主要在个人微信且不愿迁的，不接——个人微信无 API，闭环断裂）
  4. 老板本人参与访谈、指定 1 名店长级接口人
  5. 有续费/复购业务（纯一次性消费的店没得做）

## 三、四周怎么干（核心）

### 第 1 周 · 诊断周（不写一行代码）

| 天 | 动作 | 产出 |
|---|---|---|
| D1-D2 | **老板深访十问**：新客从哪来 / 续卡率 / 不该走的客户 / 常聊话题 / 判断能否续的信号 / 主动联系习惯 / 最反感员工什么 / 销冠差距在哪 / 新人怎么带 / 三个月后想看什么数 | 《老板经营原则一页纸》（全程录音） |
| D3 | **影子观察**：跟前台+顾问各半天，只看不动手——看"变通"不看"流程"（她真信哪张表、真习惯怎么跟、哪些没人写下来的惯例） | 观察表 |
| D4-D5 | 数据摸底：会员名单+卡项 / 90 天课消 / 到店记录 / 企微标签 / 老板+销冠成交聊天记录 | 《客户档案表》 |
| 周末 | 出方案签确认 | 《诊断报告》+《场景确认书》（老板签字） |

**《客户档案表》核心字段**：卡种/到期日、剩余课时+课消速度、最近到店/30 天到店次数、体验课状态、身体目标与禁忌、老板信任度分级（A/B/C）、最近互动日期。

**《场景确认书》关键动作**：只锁定**一个**首攻场景；验收指标两层写法（见第五节）；**基线数据本周就取**（错过永不再来）。

### 第 2 周 · 搭建周

1. **话术库两层提炼**（蓝蓝主刀）：
   - 第一层分类打标（6 类起步）：破冰开场 → 体验课邀约 → 到店约课 → 催续 → 流失挽留 → 价格异议；每条标来源（老板/销冠）+ 适用客户状态 + 是否带来过成交
   - 第二层老板原则编码（进系统规则），如："到期前 30 天才提续费，之前只聊训练效果""客户说贵先问目标不先降价""A 类老板亲自跟"
2. **智能体配置**（吴松海）：输入=档案行+场景+老板原则+话术库；输出=≤3 行可直接发送的草稿（老板语气，结尾带动作钩子）；语气取老板真实聊天 20 条做样本，负面清单按访谈写；红线=不承诺效果、不报价（涉及钱提示员工报老板）
3. **企微接入**：作战清单走内部群机器人/应用消息**推给员工**；保留"贴客户消息→出建议回复"辅助入口；无开发资源走低配（档案表+网页版+群机器人定时推送）
4. **周四五灰度试跑**：选 1-2 个**最能聊**的顾问（不是最闲的），真实客户真实发送；每天收她改的话术——**她改的每一处都是情报**

### 第 3 周 · 激活周

1. **作战清单上线**（主出口），首期只开 4 条规则，跑稳再加：

| 规则 | 触发 | 动作 |
|---|---|---|
| 续费预警 | 到期前 7 天 | 催续话术（按卡种/信任度分级） |
| 流失预警 | 连续 21 天未到店 | 关怀+约课话术 |
| 体验课未转化 | 课后 48h 未约 | 跟进话术 |
| 沉睡唤醒 | 私域 30 天无互动 | 轻互动话术（不推销） |

2. 每早 9:00 推送：今日名单（5-8 人，超 10 人说明规则太松）+ 每人一条话术草稿 + 一键复制；**发送结果当天四状态点选回流**（已联系/已回复/已约到店/已成交——多一步操作就会死）
3. **48 小时热修复**：员工吐槽公开修，修完群里回谢——第一个月攒的是"这团队是来真的"
4. **共作者机制**：最能聊的顾问当共作者，她改的话术正式入库标注"按 XX 经验调整"；老板带头用
5. 培训只做 **30 分钟场景化**：不讲功能，只讲"看清单、发话术、标结果"三件事

### 第 30 天 · 陪跑期

- **每周价值周报**（=账单）：本周回访 X 人/回复率/约到店/续费 X 单 ¥X,XXX + 对比基线 ±X% + 下周只调一处
- 每周一次 30 分钟复盘（老板+接口人+交付顾问），**只动一条规则或一类话术**
- **移交**：店内运营者（接口人）接《运营手册》——改规则/补话术/看周报各一页图文；**交付结束标志：交付顾问撤场两周，系统照转**
- 第 30 天周报后谈月费续费 + 索取**同行老板参访**（FDE 最强的销售资产）

## 四、企微铁律（写给团队，也写给客户）

1. **AI 只出草稿，绝不直接发客户**——官方硬限制：客户群机器人打不通；客户群发 API 需成员确认且有每月频次上限。所有触达经员工手。
2. **个人微信客户 = 高危**：无 API，系统够不着；主要客户在个人微信且不愿迁企微的店不接。
3. **会话存档 = 可选增强**（需员工+客户双方授权），首期靠四状态点选回流；客户要"全自动记录"再谈存档增购。
4. **本期明确不含**（写进场景确认书防预期膨胀）：朋友圈代运营 / 转介绍机制 / 直播——列为二期增购项。

## 五、验收与收费（两层指标）

**过程指标（写进承诺，系统可控）**：
- 上线 30 天内每周主动回访 ≥30 人
- 预警名单触达率 100%
- 消息回复率 ≥ 基线 +10 个百分点

**结果指标（挂效果月费，不签军令状）**：
- 续费/到店转化较前 90 天基线的提升幅度 → 达标收全款月费，不达标按档减免（档位写进合同）

| 项目 | 金额（样板价，可调） | 说明 |
|---|---|---|
| 诊断费 | ¥999-2,999 | 前置筛选，签约后抵扣；不肯付的不是客户 |
| 交付费 | ¥12,800-19,800 | 3 周交付，首店样板价（正价线 5-20 万另议） |
| 效果月费 | ¥1,500-3,000/月 | 与结果指标挂钩，周报即账单 |

**合同六要件**（原五件+1）：指标定义 / 基线与测量窗口 / 判定方与数据源（共认周报）/ 争议处理 / 流产条款 / **数据保密与使用范围**（会员数据与聊天记录仅用于本项目、交付后处置方式）。

## 六、风险预案

| 风险 | 信号 | 预案 |
|---|---|---|
| 数据拿不出来 | 收银系统不开放 | 手工导 90 天表起步；再不行"读旧写新"，档案人工维护两周 |
| 员工抵触 | "机器人写的不敢发" | 回共作者机制：她改、改了算她的；只推草稿不推必发 |
| 老板失联 | 访谈后消失 | 启动流产条款；系统降级纯周报模式保数据 |
| 效果不达 | 第 4 周周报低于基线 | 按序排查：名单规则太松？话术不像人话？触达时间不对？只动一处 |
| 智能体张冠李戴 | 话术错配客户 | 查档案字段喂入；收缩场景只保续费预警一条 |
| 会员数据外泄 | 老板问数据安全 | 数据条款兜底：仅本项目使用、最小必要字段、交付后删除或返还 |

## 七、做完一家沉淀什么（七件套资产）

1. 行业话术库分类框架（美业版+负面语气清单）
2. 客户档案表模板
3. 作战清单触发规则库
4. 老板访谈十问 + 影子观察表
5. 企微接入配置 SOP（含低配方案）
6. 价值周报模板 + 验收指标库
7. 交付复盘教训库（首店踩坑全记）

**复制路线**：第二家交付周期砍 40%（四人组→1 名交付顾问轻交付）；第三家同行业诊断周压到 3 天；**第 N 家定制量必须小于第 1 家——不递减就是在做驻场外包**。正价升级路径：单店样板 → 连锁多店（5-20 万）→ "AI 工作台"按月订阅（定制转产品）。
