# 美业 AI 私域作战系统 · 交付 SOP（以瑜伽馆为样板）

> 定位：面向中小美业门店（瑜伽馆 / 美容院 / 私教工作室等）的轻量 AI 落地交付手册。
> 方法论源头：范冰《前线部署工程师（FDE）》——影子工作法、MVD 最小可行部署、训练营、热修复、按结果收费、知识转移。
> 版本：v0.1（2026-11-04，待第一家样板店实战后回填修订）

---

## 〇、总览

| 项 | 内容 |
|---|---|
| 交付物 | 一个接入企微的「私域作战系统」：客户档案 + 销冠话术库 + 智能体 + 每日作战清单推送 + 每周价值周报 |
| 交付周期 | 3 周交付 + 30 天陪跑 |
| 交付人力 | 1 名交付顾问（外部）+ 客户侧 1 名拍板人（老板）+ 1 名接口人（店长/前台主管） |
| 核心理念 | 不是给员工造一个「问答机器人」，而是造一个「每天主动派单、自带战报」的作战系统 |

**为什么不是纯问答机器人**（给客户讲的口径）：
1. 被动——员工不问，系统就是死的（企业 AI 落地第一大死因）；
2. 通用——不认识具体客户，给不出「这个人、现在、该怎么聊」；
3. 无闭环——说不出帮老板赚了多少钱，月费没有依据。

## 一、接单标准（售前筛选）

照 FDE「拒绝机制」执行，三类高危信号亮两个就不接：

- ✅ **必问三件事**：
  1. 会员数据在哪？（收银系统 / Excel / 纸质台账——只要能导出就行，烂没关系）
  2. 客户沟通在哪个平台？（企微 / 个人微信——个人微信需评估迁移成本）
  3. 谁拍板、谁配合？（老板必须本人参与访谈；指定 1 名店长级接口人）
- ⛔ **不接**：只想「了解一下 AI」的；老板全程不露面、只让店员对接的；会员不到 100 人且无续费业务的（数据地基太薄，先去买 AI 课）。
- **诊断费前置**：签约前先收一笔诊断费（建议 999～2999 元，按当地消费力定）。产出诊断报告 + 场景确认书；若后续签交付，诊断费抵扣。**连诊断费都不肯付的，不是客户。**

## 二、第 1 周 · 诊断周

> 目标：摸清家底，锁定唯一场景，写死验收指标。本周不写一行代码。

### D1～D2：老板深访（1.5～2 小时）

访谈提纲（十问）：

1. 现在一个月新客几个？分别从哪来？
2. 续卡率大概多少？什么样的客户会续，什么样的不会？
3. 上个月流失的客户里，有几个是你觉得「不该走的」？为什么走了？
4. 你自己跟客户聊天，最常聊的五个话题是什么？
5. 你判断一个客户「能不能续」，看哪几个信号？（挖判断原则）
6. 什么情况下你会主动联系客户？多久联系一次？
7. 你最反感员工跟客户聊天时的哪种表现？
8. 员工跟客户聊，跟你自己聊，差距在哪？（挖「销冠为什么是销冠」）
9. 给一个刚入职的顾问，你上手带她几天？教什么？（挖隐性 SOP）
10. 这个项目成了，你希望三个月后看到什么数字？（把验收指标从他嘴里问出来）

> 要点：聊天记录给「什么」（行为），访谈给「为什么」（原则）。两样合起来才是智能体的魂。全程录音，事后整理成《老板经营原则一页纸》。

### D3：影子观察（跟班一天）

跟前台 + 顾问各半天，只看不动手，填观察表：

| 观察点 | 记录 |
|---|---|
| 她今天打开过哪些系统/表格/群？各几次？ | |
| 客户信息在哪些地方之间复制粘贴？ | |
| 哪一步最耗时间？ | |
| 哪一步她明显不耐烦/皱眉？ | |
| 客户来了消息，她多久回？回之前会问谁？ | |
| 有没有「这事要问XX」的时刻？ | |

> 重点看「变通」不看「流程」：她真正信任的数据源（往往是自己那张表）、真正的跟进习惯、没人写下来的惯例。

### D4～D5：数据摸底 + 建档案表

**数据清单（逐项确认拿取方式）：**
- 会员名单 + 卡项（卡种、购卡日、到期日、剩余课时/次数）
- 消费/课消记录（最近 90 天）
- 到店记录（最近到店日期、频次）
- 企微标签、客户备注
- 历史聊天记录导出（老板+销冠的，重点取成交会话）

**产出《客户档案表》**（一张表，字段固定，后续一切智能体输出以它为准）：

| 字段 | 说明 |
|---|---|
| 姓名/企微ID | 唯一标识 |
| 卡种/到期日 | 续费作战的核心字段 |
| 剩余课时 + 课消速度 | 推算「还剩几天用完」 |
| 最近到店日期 / 30天到店次数 | 流失预警的核心字段 |
| 体验课状态 | 未转化跟进用 |
| 身体目标/禁忌（备注） | 话术个性化素材 |
| 老板信任度分级（A/B/C） | 分级话术强度 |
| 最近互动日期 | 沉睡预警用 |

### 周末产出与过关标准

1. **《诊断报告》**：现状 + 三个最值钱的场景 + 推荐的第一场景（只选一个）；
2. **《场景确认书》**：一页纸，老板签字。核心是**验收指标写死成一个数**，例如：
   - 「上线 30 天内，每周主动回访 ≥ 30 人，流失预警名单触达率 100%，续费/到店转化较前 90 天基线提升 ≥ 20%」（基线数据本周就取，错过永不再来）；
3. 确认交付费与效果月费金额（见第六节）。

## 三、第 2 周 · 搭建周

> 目标：档案入库 → 话术库成型 → 智能体搭建 → 企微接入 → 1～2 人灰度试跑。

### 2.1 话术库打包（智能体的弹药）

对老板 + 销冠的成交聊天记录做两层提炼：

**第一层：分类打标**（建议 6 类起步）：
- 破冰/新客开场 → 体验课邀约 → 到店邀约/约课 → 催续（到期前）→ 流失挽留 → 价格异议处理
- 每条话术标注：来源（老板/销冠）、适用客户状态（如「到期前7天+课消正常」）、是否带来过成交（能标尽量标）

**第二层：老板原则编码**：把访谈里的判断原则写成智能体的系统规则，例如：
- 「到期前 30 天才开始提续费，之前只聊训练效果」；
- 「客户说贵，先问目标，不先降价」；
- 「A 类客户老板亲自跟，B/C 类员工跟」。

### 2.2 智能体搭建（配置要点）

- **输入**：客户档案行 + 场景 + 老板原则 + 对应分类话术库；
- **输出**：一条可直接发送的话术草稿（老板语气），不超过 3 行，结尾必带一个动作钩子（约时间/约体验/给反馈）；
- **语气规范**：取老板真实聊天 20 条做风格样本，禁用「亲」「呢」等美业腔（按访谈里老板反感的写负面清单）；
- **红线**：不承诺效果、不报价格折扣（涉及钱的必须提示员工报老板）。

### 2.3 企微接入

- **推送形式**：每日作战清单（见 3.1）走企微应用消息/机器人推送到员工，**员工不用主动找机器人**；
- **问答入口**：保留一个「贴客户消息→出建议回复」的快捷入口，作为辅助模块；
- **低配替代方案**（客户没有开发资源时）：档案表 + 智能体网页版 + 清单用企微群机器人定时推送，先跑通闭环，不做深度集成。

### 2.4 灰度试跑（周四周五）

选 1～2 个最能聊的顾问（注意：选最强的，不是最闲的），真实客户、真实发送。每天收工收集：哪条话术她改了？改了什么？为什么？——**她改的每一处都是情报**。

## 四、第 3 周 · 激活周

> 目标：全员用起来，形成习惯。激活的标准不是「上线」，是「老板不催，系统每天自己转」。

### 3.1 作战清单上线（系统的主出口）

触发规则库（首期只开 4 条，跑稳再加）：

| 规则 | 触发条件 | 动作 |
|---|---|---|
| 续费预警 | 到期前 7 天 | 出催续话术（按卡种/信任度分级） |
| 流失预警 | 连续 21 天未到店 | 出关怀+约课话术 |
| 体验课未转化 | 体验课后 48 小时未约 | 出跟进话术 |
| 沉睡唤醒 | 私域 30 天无互动 | 出轻互动话术（不推销） |

每日早上 9:00 推送：今日名单（5～8 人，超 10 人说明规则太松）+ 每人一条话术草稿 + 一键复制。**发送结果当天回流**：已联系/已回复/已约到店/已成交，四个状态点选即可（增加操作就会死）。

### 3.2 48 小时热修复机制

公开承诺：员工吐槽的问题，48 小时内给答复或修好。修完在群里公开回谢提意见的人。**第一个月攒下的不是功能，是「这个团队是来真的」这个判断。**

### 3.3 影响者经营

- 请最能聊的顾问当「共作者」：她改过的话术正式入库，标注「按XX的经验调整」；
- 高管（老板）先带头用：老板自己的回访也从清单里点；
- **不做全员大会培训**，只做 30 分钟场景化培训：不讲功能，讲「你每天早上看清单、点发送、标结果」这三件事。

## 五、第 30 天 · 陪跑期

> 目标：出第一个价值周报，把运营权移交给店里，谈续费。

- **每周价值周报**（固定模板，发老板）：
  - 本周回访 X 人 / 回复率 X% / 约到店 X 人 / 续费 X 单 ¥X,XXX；
  - 对比基线：较上线前 90 天均值 ±X%；
  - 下周计划（调哪条规则/哪类话术）。
- **调优节奏**：每周一次 30 分钟线上复盘（老板+接口人+交付顾问），只动一处（一条规则或一类话术），避免折腾。
- **移交（知识转移）**：选出店内运营者（通常是接口人），移交《运营手册》——改规则、补话术、看周报三件事各配一页图文。**交付结束的标志：交付顾问撤场两周，系统照转。**
- **续费节点**：第 30 天周报后谈效果月费；同时索取转介绍（同行老板参访——背书是 FDE 模式最强的销售资产）。

## 六、收费结构（混合制，照 FDE 中国市场计价）

| 项目 | 金额（建议区间） | 性质 |
|---|---|---|
| 诊断费 | ¥999～2,999 | 前置筛选，签约后抵扣 |
| 交付费 | ¥8,000～20,000（按门店规模/城市） | 3 周交付一次性 |
| 效果月费 | ¥1,500～3,000/月 | 续费金额或到店增量的挂钩档；周报即账单 |

**合同五要件**（缺一不可）：指标定义（什么叫「续费成功」）、基线与测量窗口（前 90 天均值）、判定方与数据源（双方共认的周报，不认单方报表）、争议处理、流产条款（客户数据拿不出来/人员不配合时费用怎么算）。

## 七、风险预案

| 风险 | 信号 | 预案 |
|---|---|---|
| 数据拿不出来 | 收银系统不开放导出 | 手工导一张 90 天表起步；实在不行按「读旧写新」只读不写，档案表人工维护两周 |
| 员工抵触 | 「机器人写的我不敢发」 | 回到共作者机制：让她改、改了算她的；先只推「草稿」不推「必发」 |
| 老板失联 | 访谈后不再出现 | 启动流产条款；系统降级为纯周报模式保住数据 |
| 效果不达 | 第 4 周周报低于基线 | 复盘三条：名单规则太松？话术不像人话？触达时间不对？按序排查，先动一处 |
| 智能体答非所问 | 话术张冠李戴 | 检查档案字段喂入是否正确；收缩场景，只保续费预警一条规则 |

## 八、可复制资产清单（做完一家，沉淀什么）

按 FDE「打法手册七件套」对照，每交付一家，以下入库一份、修订一版：

1. 行业话术库分类框架（美业版，含负面语气清单）
2. 客户档案表模板（字段即上表，可直接复用）
3. 作战清单触发规则库（按行业增删）
4. 老板访谈十问 + 影子观察表
5. 企微接入配置 SOP（含低配替代方案）
6. 价值周报模板 + 验收指标库
7. 交付复盘教训库（第一家店踩的坑全部记入）

> 复制逻辑：第二家店交付周期目标砍 40%；第三个同行业客户起，诊断周可压缩到 3 天。**第 N 个客户的定制量必须小于第 1 个——不递减，就是在做驻场外包。**
