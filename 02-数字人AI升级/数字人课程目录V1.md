## 学习路径

### SYNC · 01 先导同频课

**先看懂，再动手做**
LEARN · THEN BUILD

- 第 1 节｜怎么用数字人：重复出镜、批量口播交给分身；判断、关系和信任必须留给人
- 第 2 节｜合规红线：AI 生成内容必须标识，平台规则先看清再做

### S01 · 02 分身塑造系统

**形象 · 声音 · 表达 · 人设**
AVATAR · VOICE · TONE · PERSONA

- 形象克隆：真人形象采集与授权
- 声音克隆：音色 / 语速 / 情绪还原
- 表达风格：口头禅、逻辑习惯、话术节奏
- 人设统一：数字人与真人 IP 口径保持一致

### S02 · 03 内容量产系统

**选题 · 脚本 · 生成 · 剪辑**
TOPIC · SCRIPT · GENERATE · EDIT

- 选题库：从客户问题和产品卖点里挖选题
- 脚本批量生成（同一观点出多个版本）
- 数字人成片批量产出
- 剪辑与多版本复用（横屏 / 竖屏 / 短切）

### S03 · 04 矩阵分发系统

**平台 · 节奏 · 标识 · 承接**
PLATFORM · RHYTHM · LABEL · CONVERT

- 多平台格式适配（视频号 / 抖音 / 小红书）
- 发布节奏与排期表
- AI 内容标识与平台合规
- 公域到私域的承接动线

### S04 · 05 全员视频系统

**矩阵 · 分身 · 日更 · 抗风险**
MATRIX · CLONE · DAILY · SHIELD

- 账号矩阵：全员开号，不把量押在一个 IP 或一个账号上
- 每人分身：不愿出镜、不会拍的员工也能产出视频
- 日更供给：总部统一出选题与脚本，全员分发各发各的
- 抗封号：分散发布 + 内容差异化，一号出事不伤全局

### S05 · 06 全域复用系统

**种草 · 答疑 · 交付 · 定制**
MOMENTS · FAQ · DELIVER · PERSONAL

- 朋友圈 / 社群种草素材日更供给
- 高频答疑做成数字人短片
- 课程 / 内训 / 交付内容复用再生产
- 千人千面：不同客户出不同称呼的讲解视频

### —— 1 套 数字人中台

**后台支撑，开箱即用，不单独教**
资产库 · 脚本库 · 素材库 · 合规库
ASSET · SCRIPT · MATERIAL · COMPLIANCE

- 分身资产：形象 / 声音 / 授权文件统一管理
- 脚本库：选题、脚本、话术沉淀
- 素材库：成片 / 字幕 / BGM / 封面 复用
- 合规库：敏感词与 AI 标识规则

### FINAL · 07 最小闭环

**诊断 · 搭建 · 跑通 · 验影响**
DIAGNOSE · BUILD · RUN · VERIFY

- 选 1 个最痛场景（建议：内容量产）
- 七天产出一轮真实内容并发出去
- 拿行为证据：播放 / 加微 / 留资 有没有涨
- 决定：继续 / 调整 / 停止
