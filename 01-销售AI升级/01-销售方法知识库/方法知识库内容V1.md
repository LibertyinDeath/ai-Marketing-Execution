# 模块 1 · 销售方法知识库 · 内容 V1（销冠打法底料）

> 母本：《门店销售三段论》（全文整合）
> 定位：底座 · 全课可调用的销售方法论沉淀
> 📌 要点版，不写成段话术
> ⚠️ 资料源自门店（美业）语境，企业私域课使用须**脱敏 + 换语境**（"面膜/体验卡/门店"→ 客户自家产品/线上诊断/私域）
> 📖 古文锚：一旦加入即固定，不可删

## 一、模块目标
沉淀一套企业可复用的**销售方法论库**（成交逻辑 / 需求诊断 / 价值包装 / 对话原则 / 客户分类 / 目标管理），全课 16 模块随时调取。

## 二、微信成交四步逻辑（全课主线）
1. 自我介绍（破冰立人）
2. 需求诊断（发问挖需求）
3. 塑造卖点（相关 + 能解决）
4. 成交促单（临门一脚）
> 与"成交三要素（动机→信任→临门一脚）"并轨，不两套逻辑打架。
> 📖 《传习录》"知是行之始，行是知之成"——懂逻辑才能复制成交

## 三、需求诊断：马斯洛五层 + 五式发问
- 五层：生理 / 安全 / 社交 / 尊重 / 自我实现
- 五式发问：启发式 / 对比式 / 过去式 / 现在式 / 未来式
- 核心：别"查户口"，用发问层层进客户内心；根据回答推敲真需求

## 四、产品价值包装五维（→ 模块 2 产品资料库字段）
1. 成分（材料 / 制作流程）
2. 人物（谁制作 / 谁说好）
3. 效果（用了会怎样）
4. 信任（专业方案解答 / 让他放心）
5. 客户见证（评价 / 对比 / 视频 / 权威推荐）
> 包装 ≠ 吹牛，是"让他觉得相关 + 能解决"

## 五、客户对话三原则
- 共鸣 / 请教 / 专业
- 永远不和客户对抗；客户只是想买性价比最高的，不是较劲

## 六、四类客户 × 六法成交（→ 模块 5/12）
- 四类：价格 / 效果 / 从众 / 态度敏感
- 六法：直接 / 损失 / 方案 / 福利 / 假设 / 感动

## 七、目标分解与全员营销（→ 模块 15）
- 目标分解：年→季→月→周→天，责任到人
- 客户二分：新客发掘 / 老客续费升单
- 士气四因：目标含糊 / 方法缺失 / 回报不足 / 信任缺失
- 复盘五步：回顾目标 / 评估方法 / 反思过程（找亮点+不足+变化项+标杆）/ 总结规律 / 形成记录

## 八、知识库使用规则
- 所有条目脱敏，禁出现"朱老师/尹老师/门店/面膜"等原语境词
- 新销冠案例持续入库，知识库只增不删
- 与模块 5 话术库、模块 12 对练题库同源同源

## AI 结合点
- 知识库结构化后喂 AI，新人提问即答（内部顾问）
- 销冠新记录自动提取进库（见模块 5 搭建法）
