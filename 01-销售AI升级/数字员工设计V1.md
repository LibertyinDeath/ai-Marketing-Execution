# 销售 AI 升级 · 企微数字员工设计 V1

> 背景：第 1 个数字员工已建 = **朋友圈运营员**（每日自动生成朋友圈素材 → 发到群里）
> 目标：按 16 个功能板块，设计可落在企微里的数字员工矩阵
> 日期：2026-10-28
> 铁律：**减负不增负**——每个员工上线前问"让销售少干了还是多填表了"，增负的直接否

---

## 一、统一交互范式（所有员工共用）

```
定时自动跑 → 产出"可直接用的东西" → 推进企微群/个人 → 人只"看一眼/点确认"
```

- **人绝不填表**：任何要销售录入/填日报的员工，改成 AI 自动取数生成。
- **产物形态**：素材 / 话术 / 名单 / 提醒 / 报告 —— 拿到就能用，不用再加工。
- **人类动作上限**：看一眼、点确认、选一条发。**超过这三个动作就是增负。**

---

## 二、企微能力边界（硬约束 · 2026-10-28 官方核实）

> **结论：企微「群机器人 / 智能机器人」打不通外部群（客户群）——这是官方硬限制，不是配置问题。**

### 官方口径
- 群机器人 / 智能机器人 **仅支持内部群**；互联群、外部群（客户群）**不支持添加**
- 客户群也**不能添加自建应用**；应用消息不支持发到外部群
- 要**读**客户群聊天内容 → 只能用**会话内容存档**
- （边缘：上下游群面向经销商场景，第三方称可通过「消息推送」配置，官方口径不一，且不适用于客户群场景）

### 往客户群发消息的唯一合规路径：「创建群发」接口
- 接口：`externalcontact/message/send`（官方文档 92135 / 92698）
- **两个限制必须知道**：
  1. **不会直接发出**——创建的是群发任务，需**成员在客户端确认**后才发送 → **不是完全无人值守**
  2. **频次上限**——每位客户 / 每个客户群**每月最多接收 = 当月天数**；可在「群发助手 → 设置群发规则」调成每周 7 条或每天 1 条
- 客户群**支持**的轻量自动化：入群欢迎语、关键词自动回复

### 灰色路径（不建议，FDE 交付不能赌）
- 让真人企微账号待在群里，用第三方账号级 API / RPA 驱动发言
- 违反企微条款、**封号风险高**，卖给客户等于埋雷

### 对数字员工矩阵的影响（按触达对象分三类）

| 类型 | 涉及员工 | 触达方式 | 自动化程度 |
|---|---|---|---|
| **纯对内**（推给团队看）| 朋友圈✅ / 话术弹药员 / 群运营员(内容包) / 发售操盘员 / 陪练员 / 跟单督导员 / 数据看板员 / 目标激励员 / 知识库管理员 | 内部群 webhook | ✅ **完全自动** |
| **客户触达** | 群运营员(对外) / 私聊种草员 / 新客承接员 / 老客激活员 / 二转复购员 / 交付交接员 | 客户群发 API | ⚠️ AI 拟稿+建任务，**人点确认** |
| **读客户数据** | 客户档案员 / 话术弹药员(提取) / 交付交接员(承诺提取) | 会话内容存档 | 需双方授权 |

> **关键结论**：推给内部团队看的员工（多数）webhook 完全够用、**今天能做**；直接触达客户的员工必须走客户群发 API + 人点确认，且受每月频次限制。
> 这不破坏减负——人只"点确认"，不写不填，仍符合 FDE 红线。

## 四、逐个设计要点（关键细节）

### 1. 新客承接员（模块 04）—— 业务价值最高
- 触发：新好友加入 → 秒级
- 动作：发欢迎语+人设卡+低门槛钩子 → 2h 诊断破冰 → 当日给专业建议 → 24h 邀约下一步
- 自动打来源标签；24h 未回复二次触达
- ⚠️ 对外首触走**客户群发 API + 成员确认**，不是 webhook 直发
- **减负点**：销售不再手动打招呼、不再漏跟新客

### 3. 话术弹药员（模块 05）—— 销冠经验不流失
- 定期扫销冠脱敏聊天 → 提取高频句 → 按成交四步归类
- 生成异议话术库；每日推"今日一条话术"到**内部群**（webhook 直发）
- **减负点**：不用人写话术、不用人整理

### 5. 群运营员（模块 08）—— 拆对内 / 对外两版
- **对内版（今天能做）**：生成"今日群内容包"（晨报/答疑/案例/互动话题）→ webhook 推内部群 → 销售复制发到自己的客户群
- **对外版（受限制）**：走客户群发 API 建任务 → 成员点确认发出；受每月频次上限
- 意向提取：群内互动标红 → 推销售跟进（需会话存档读群聊）
- **减负点**：销售不用想内容，复制即用

### 9. 销售陪练员（模块 12）—— 零依赖、最易见效
- AI 扮演四类难缠客户（价格/效果/从众/态度敏感）
- 用**成交四步**当评分标尺自动打分，上岗考核 ≥80 分
- 完全对内、webhook 直发，**无任何企微限制**
- **减负点**：不占销冠时间，新人自练

### 13. 交付交接员（模块 16）—— 防过度承诺退单
- 成交后扫聊天 → 提取"承诺句" → 生成《承诺交接单》
- 超红线（绝对化用语/保效果）自动预警
- **减负点**：销售不用写交接单，AI 提取

### 14. 知识库管理员（模块 01+02）—— 所有员工的粮仓
- 产品资料库（五维：成分/人物/效果/信任/见证）+ 方法库（成交四步/发问/四类六法）
- 销冠新记录自动入库；销售问产品/打法即答
- **减负点**：新人不用背产品，问就行

## 五、建设优先级（按依赖分档，别一窝蜂上）

| 档 | 条件 | 员工 | 建议 |
|---|---|---|---|
| **T0 零依赖**（内容生成型，全对内）| 不需要客户数据，喂资料就能跑 | 朋友圈✅ / 群运营员(对内) / 发售操盘员 / 销售陪练员 / 知识库管理员 | **今天就能建** |
| **T1 需客户/订单数据** | 有名单/订单 + 群发API | 老客激活员 / 二转复购员 / 目标激励员 | 整理名单后建 |
| **T2 需会话存档 + 群发授权** | 企微会话存档（双方授权）+ 群发规则配置 | 新客承接员 / 客户档案员 / 话术弹药员 / 私聊种草员 / 交付交接员 | **同步启动授权**，授权后价值最大 |
| **T3 需过程数据沉淀** | 依赖前面员工产出的数据 | 跟单督导员 / 数据看板员 | 最后建 |

## 六、建议：先补这 3 个

1. **群运营员（对内版）**（T0）—— 和朋友圈员完全同范式、同群、同 webhook，最容易复制，明天能上线
2. **销售陪练员**（T0）—— 零依赖、无任何企微限制、独立可跑，老板最爱看效果
3. **新客承接员**（T2，但最高价值）—— 同步做两件事：**申请会话存档**（读）+ **配置群发规则**（发，建议先设"每天 1 条"）

> 会话存档 = 读的开关；群发 API = 发的开关。两个都要办，客户触达类员工才跑得通。

## 七、待宝总拍板

1. 先补哪 3 个（建议：群运营员对内版 / 陪练员 / 承接员）
