# 销售 AI 升级 · 企微数字员工设计 V1

> 背景：第 1 个数字员工已建 = **朋友圈运营员**（每日自动生成朋友圈素材 → 发到群里）
> 目标：按 16 个功能板块，设计可落在企微里的数字员工矩阵
> 日期：2026-10-28
> 铁律：**减负不增负**——每个员工上线前问"让销售少干了还是多填表了"，增负的直接否

---

## 一、统一交互范式（所有员工共用）

```
定时自动跑 → 产出"可直接用的东西" → 推进企微群/个人 → 人只"看一眼/点确认"
```

- **人绝不填表**：任何要销售录入/填日报的员工，改成 AI 自动取数生成。
- **产物形态**：素材 / 话术 / 名单 / 提醒 / 报告 —— 拿到就能用，不用再加工。
- **人类动作上限**：看一眼、点确认、选一条发。**超过这三个动作就是增负。**

## 三、逐个设计要点（关键细节）

### 1. 新客承接员（模块 04）—— 业务价值最高
- 触发：新好友加入 → 秒级
- 动作：发欢迎语+人设卡+低门槛钩子 → 2h 诊断破冰 → 当日给专业建议 → 24h 邀约下一步
- 自动打来源标签；24h 未回复自动二次触达
- **减负点**：销售不再手动打招呼、不再漏跟新客

### 3. 话术弹药员（模块 05）—— 销冠经验不流失
- 定期扫销冠脱敏聊天 → 提取高频句 → 按成交四步（自我介绍/诊断/卖点/促单）归类
- 生成异议话术库；每日推"今日一条话术"到群
- 新人提问即答（内部顾问）
- **减负点**：不用人写话术、不用人整理

### 9. 销售陪练员（模块 12）—— 零依赖、最易见效
- AI 扮演四类难缠客户（价格/效果/从众/态度敏感）
- 用**成交四步**当评分标尺自动打分，上岗考核 ≥80 分
- **减负点**：不占销冠时间，新人自练

### 13. 交付交接员（模块 16）—— 防过度承诺退单
- 成交后扫聊天 → 提取"承诺句" → 生成《承诺交接单》
- 超红线（绝对化用语/保效果）自动预警
- **减负点**：销售不用写交接单，AI 提取

### 14. 知识库管理员（模块 01+02）—— 所有员工的粮仓
- 产品资料库（五维：成分/人物/效果/信任/见证）+ 方法库（成交四步/发问/四类六法）
- 销冠新记录自动入库；销售问产品/打法即答
- **减负点**：新人不用背产品，问就行

## 四、建设优先级（按依赖分档，别一窝蜂上）

| 档 | 条件 | 员工 | 建议 |
|---|---|---|---|
| **T0 零依赖**（内容生成型）| 不需要客户数据，喂资料就能跑 | 朋友圈✅ / 群运营员 / 发售操盘员 / 销售陪练员 / 知识库管理员 | **今天就能建** |
| **T1 需客户/订单数据** | 有名单/订单就能跑 | 老客激活员 / 二转复购员 / 目标激励员 | 整理名单后建 |
| **T2 需会话存档授权** | 企微会话存档 + 双方授权 | 新客承接员 / 客户档案员 / 话术弹药员 / 私聊种草员 / 交付交接员 | **同步启动授权**，授权后价值最大 |
| **T3 需过程数据沉淀** | 依赖前面员工产出的数据 | 跟单督导员 / 数据看板员 | 最后建 |

## 五、建议：先补这 3 个

1. **群运营员**（T0）—— 和朋友圈员完全同范式，最容易复制，零依赖，明天就能上线
2. **销售陪练员**（T0）—— 零依赖、独立可跑、销冠经验复制，老板最爱看效果
3. **新客承接员**（T2，但最高价值）—— 业务价值第一，**同步去把企微会话存档授权办了**（需员工+客户双方同意）

> 会话存档是 T2 五个员工的共同开关，早授权早解锁。个人微信无官方 API，不碰逆向。
