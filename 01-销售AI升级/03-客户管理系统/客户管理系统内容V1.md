## 一、模块目标
定义企业私域"客户操作系统"的字段与流程，让流量接得住、跟得动、转得清、复得明。

## 二、系统定位
- 不是重 CRM，是轻量私域客户资产表（企微 / 飞书 / 表格均可落地）
- 核心：每个客户的"人 + 需求 + 阶段 + 价值"可执行记录

## 三、客户档案字段
1. **基础信息**：来源 / 加微时间 / 渠道
2. **购买力与需求**（母本§二.2 测试表）
   - 消费水平信号、核心需求点、预算区间
3. **分层标签**
   - 新客发掘 / 老客续费升单（母本客户二分）
   - 类型：价格 / 效果 / 从众 / 态度敏感（接模块 5）
4. **生命周期阶段**：陌生 → 加微 → 深聊 → 成交 → 复购 → 沉睡
5. **跟进记录**：每次触点 / 内容 / 下一步
6. **价值字段**：客单价 / LTV / 转介绍贡献

## 四、系统要支撑的四个动作
- 承接：加微自动打"来源标签" + 首触动线（接模块 4）
- 跟单：SOP 提醒（接模块 13）
- 复购：二转埋点提醒（接模块 11）
- 沉睡唤醒：激活名单导出（接模块 10）

## 五、与课程其他模块接驳
- 模块 1 方法库 / 模块 5 话术库按客户类型调取
- 模块 14 数据看板从系统取数

## 六、AI 结合点
- 聊天记录自动打标签（类型 / 需求 / 阶段）
- 沉睡客户自动标红，触发激活流程
- 跟进提醒自动生成

> 📖 《孙子兵法》"知彼知己，百战不殆"——客户档案就是知彼的底座

## 七、常见坑
- 字段太多没人填 → 只留必填 6 项
- 系统是死的，人是活的 → 每周清盘一次
- 只记不分析 → 接模块 14 周复盘
