## 一、课程信息卡

| 项 | 内容 |
|---|---|
| 课程名称 | 销售 AI 升级实战营 |
| 目标学员 | 中小企业老板 + 销售主管 + 一线销售（**企业组队参训，每家 2~3 人**） |
| 学员前置 | 完成《AI 认知第一课》或同等认知（会基础对话、知道大模型 vs 智能体） |
| 时长 | **2 天线下集训（16 课时）+ 30 天线上陪跑（约 8 课时）** |
| 班级规模 | 首期建议 20~30 家企业 |
| 课程性质 | 技能型课程，实操占比 ≥60% |
| 结营交付 | 承接 SOP + 销转话术手册 + AI 对练系统 + 转化数据看板（四件全带走） |

## 二、学习目标（结营时学员能够……）

1. **搭建**一套自己产品的 AI 私域承接 SOP：黄金 24 小时动线 + 话术库 30 条，新流量加微后 5 分钟内完成首次标准化触达
2. **用 AI 分析**自家成交聊天记录，提取成交路径与高频异议应答，产出销转话术手册（≥20 条异议全覆盖）
3. **搭建**「难缠客户」AI 模拟对练系统，新人上岗前完成对练考核
4. **搭建**转化数据看板（加微率/深聊率/成交率三层），跑通一次完整的「数据 → AI 诊断 → 单变量实验」周复盘
5. **说清** AI 销转的合规红线（企微风控、必须人聊的场景），AI 使用不出事故

## 四、模块大纲

### 模块 1 · AI 私域承接：流量接得住（8 课时）

| 小节 | 知识点（每半天 ≤5 个） |
|---|---|
| 1.1 承接的本质 | 不是聊得多，是 SOP 对——私域漏斗拆解（加微→首聊→激活→朋友圈渗透→成交铺垫） |
| 1.2 黄金 24 小时 | 加微后动线设计：首聊话术、资料投放、自动打标签 |
| 1.3 AI 话术库 | 销冠话术结构化 → 三场景 AI 辅助（开场/激活/异议）；信任红线：哪些必须人聊 |
| 1.4 人设朋友圈 | 三线结构：专业线/生活线/成交线 |
| 1.5 分层运营 | 按意向度分层的触达节奏 |

**实操产出**：承接 SOP 动线图 + 话术库 V1（三场景各 10 条，共 30 条）

### 模块 2 · 销冠复制：话术炼金术（4 课时）

| 小节 | 知识点 |
|---|---|
| 2.1 成交三要素 | 动机 → 信任 → 临门一脚；情感驱动优先于信息传递 |
| 2.2 销冠复盘法 | 从成交聊天记录提取成交路径——AI 辅助批量分析（脱敏后喂入） |
| 2.3 高频异议库 | 价格 / 拖延 / 比价 / 家人反对，四类应答体系 |
| 2.4 朋友圈成交线 | 发什么、何时发、发完怎么跟 |

**实操产出**：销转话术手册 V1（成交路径图 + ≥20 条异议应答）——**本模块是全课核心产出，留足实操时间**

### 模块 3 · AI 销售助理：跟单不靠自觉（4 课时）

| 小节 | 知识点 |
|---|---|
| 3.1 AI 对练系统 | 用 AI 扮演「难缠客户」的提示词设计（现场教） |
| 3.2 对练考核 | 新人上岗前的对练考核机制 |
| 3.3 跟单 AI | 跟进提醒、客户画像小结、话术建议 |
| 3.4 合规红线 | 企微风控边界、必须人聊的场景、AI 出错兜底机制 |

**实操产出**：AI 对练提示词模板 + 跟单 SOP

### 模块 4 · 转化数据看板与迭代（陪跑期 8 课时）

| 小节 | 知识点 |
|---|---|
| 4.1 看板搭建 | 转化三层漏斗：加微率 → 深聊率 → 成交率；表格起步够用 |
| 4.2 AI 诊断 | 喂数据 → 找最漏人的一层 → 给改进假设 |
| 4.3 单变量实验 | 一次只改一个变量（内容/话术/动线） |
| 4.4 周复盘固化 | 谁来、何时、看什么、改什么——从「我盯」到「系统自转」 |

**实操产出**：转化看板 V1 + 一次完整周复盘记录 + 1 个被数据验证的迭代动作

## 五、评估体系（三层闭环）

1. **随堂验收**（集训期）：三大产出物（SOP/话术手册/对练提示词）讲师+助教逐组现场检查，当场打回重做
2. **陪跑作业**（Week1-3）：看板提交、对练考核通过（每人过一遍陪练）、周复盘记录
3. **结营路演**（Week4）：30 天数据前后对比路演，师团评审 + 学员互评，评优秀案例

**结营标准**：三产出齐全 + 对练考核通过 + 路演完成。**结营挂钩下一课**：优秀案例进《引流 AI 升级》优先名额。

## 六、教学设计原则（讲师执行）

- 每半天节奏：讲授 ≤40% / 演示 20% / **实操 ≥30%** / 点评 10%
- 每个知识点配一个脱敏真实案例（源自自有团队，禁虚构）
- 线上陪跑：每周直播 + 群内作业逐份点评（点评即二次教学）
- 知识点密度：每半天 ≤5 个，超载即砍
