## 一、一句话结论

**框架不动，换操作系统**：AI 系统设计的流程主轴，从门店三段论的"四步成交"升级为贝琳达的"五环节流程"（激发欲望 → 挖需 → 演示 → 异议处理 → 关单，朋友圈贯穿全程）；挖需、客户分类、异议处理、关单、朋友圈经营、工具百宝箱六大体系整体注入 16 个模块。三段论的动作话术全部保留当血肉。

## 二、两套母本怎么融合

## 三、流程主轴升级（AI 系统设计的主线变了）

- 旧（三段论）：自我介绍 → 需求诊断 → 塑造卖点 → 成交促单
- 新（贝琳达）：**激发欲望 → 挖需 → 演示 → 异议处理 → 关单**（开发在前，朋友圈贯穿售前/售中/售后）
- 对 AI 的三个直接影响：
  1. **挖需成为 AI 最重要的战场**——销售四问（为什么买 / 为什么不得不买 / 为什么跟你买 / 为什么现在买）+ MAN 法则（钱 / 权 / 需）→ AI 自动挖需、自动建档、自动筛选（真伪 / 紧急度 / 购买力 / 决策权 / 竞品）
  2. 每个环节都有对应数字员工供弹药，环节边界清晰（挖需没到位不许演示——AI 卡流程）
  3. 朋友圈从"发内容"升级为"一对 N 的说服"，贯穿全周期

## 六、两个拍板点（需宝总定）

1. **客户分类两套并存**：门店三段论"价格 / 效果 / 从众 / 态度敏感"（定成交话术）× 贝琳达"DISC 红黄蓝绿"（定跟单策略）→ **建议并存**：AI 同时打两组标签，谈单看敏感类型，跟进看性格颜色。互不替代。
2. **转介绍归属**：贝琳达放在销售/私域卷，此前宝总定归服务板块 → 本方案按"**方法论入库模块 11、落地动作归服务课程**"处理。

## 七、不新增模块的结论

- 产品演示（第十五章）→ 并入 09 私域发售（讲解即演示）+ 02 产品资料库（演示包）
- 竞品调研（第十二章）→ 并入 05 话术库（竞品异议 + 建立选择标准）+ 03 客户系统（竞品字段）
- 时间管理 / 表达力 / 同理心 / 自信（修己篇软技能）→ 并入 12 AI 陪练（对练即训练）
- **16 模块数量保持不变**

## 八、落地节奏

1. **阶段一（入库）**：贝琳达六大体系脱敏入库，替换方法知识库内容——顺序：⑨挖需 → ⑰异议 → ⑭关单 → ⑩⑪分类性格 → ㉓㉔朋友圈 → ㉚工具箱 → ㉙漏斗 → 卷一认知 → 实战答疑（陪练题库）
2. **阶段二（改 AI）**：按新流程改数字员工提示词——四问 + MAN 进承接员/档案员，SRDS 进话术员，五层漏斗进看板员，四色标签进档案员
3. **阶段三（重做陪练）**：答疑篇实战案例变对练题库
4. **验收不变**：FDE 七天验影响——第一个客户跑通"AI 挖需建档 → 性格标签 → 针对性话术 → 关单"全流程
