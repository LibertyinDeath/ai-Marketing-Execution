## 一、模块目标
用数据盯住"转化率翻倍"北极星，每周找最漏层，做单变量实验，可测可守。

## 二、核心指标（北极星拆解）
- 北极星：成交转化率（翻倍目标）
- 漏斗层：曝光 → 加微 → 深聊 → 方案 → 成交 → 复购
- 每层转化率 = 下层 / 上层

## 三、数据看板字段
- 各层人数 / 转化率 / 周环比
- 最漏层高亮（红）
- 单客成交概率 vs 深聊数（翻倍公式：成交 = 深聊数 × 单客概率）

## 四、周复盘五步（母本§三.5）
1. **回顾目标**：总 / 阶段目标与完成比
2. **评估方法**：关键方法成效
3. **反思过程**：找亮点 / 不足 / 变化项 / 标杆
4. **总结规律**：哪些杜绝 / 继续 / 开始
5. **形成记录**：决议 + 全员会公布

## 五、单变量实验法（翻倍可守）
- 每周只改一层一个变量（如首触话术）
- 对比转化率，留优去劣
- 不一次改多头 → 不知哪有效

## 六、常见坑
- 只看 GMV 不看漏斗 → 不知漏哪
- 复盘变检讨会 → 伤士气
- 改太多变量 → 无法归因

## 七、AI 结合点
- 看板自动出，异常自动标
- AI 建议本周实验变量
- 复盘纪要自动生成
