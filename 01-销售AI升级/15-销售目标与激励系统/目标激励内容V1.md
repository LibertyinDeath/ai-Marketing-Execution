# 模块 15 · 销售目标与激励系统 · 内容 V1（管团队）

> 母本：《门店销售三段论》（§三.1 分解目标责任到人 / §三.4 士气四因 / 提成机制 / §三.3 动员会）
> 定位：过程治理 · 目标拆解到人到周 + 激励机制
> 📌 要点版，不写成段话术
> ⚠️ 门店语境须脱敏换企业私域语境
> 📖 古文锚：一旦加入即固定，不可删

## 一、模块目标
把业绩目标拆到人 / 周，配机制让团队"为自己拼"，不靠盯。

## 二、目标分解（母本§三.1）
- 年 → 季 → 月 → 周 → 天
- 责任到人：销售 + 客户二分（新客发掘 / 老客续费升单）
- 不会拆目标的销售 100% 成不了销冠

## 三、士气四因与对策（母本§三.4）
1. 目标含糊 → 拆到每天知道怎么干
2. 方法缺失 → 给计划 + 早会夕会（接模块 13）
3. 回报不足 → 加奖金（非提成比例）
4. 信任缺失 → 一对一沟通 + 聚餐找回信任

## 四、激励设计
- 提成机制公开（母本：公布提成，鼓励开单）
- 首单奖 / 标杆奖 / 冲刺奖
- 非物质：称号 / 置顶 / 请教（母本"您这么专业"）
- 第一次不定惩罚，只定目标（母本）

## 五、动员会打法（母本§三.3）
- 先共识核心人员 → 团队讨论定目标 → 领导微调（不超己定）
- 正面话为主，不批评 → 宣誓
> 士气不高时不加目标，只统一思想。

## 六、常见坑
- 目标从上压下不共识 → 抵触
- 只罚不奖 → 流失
- 提成含糊 → 不信

## 七、AI 结合点
- 目标自动拆到周 / 人，进度看板
- 落后预警 + 干预建议
- 激励方案模拟（不同提成下的产出）

> 📖 《尚书》"功崇惟志，业广惟勤"——目标立志，激励惟勤
