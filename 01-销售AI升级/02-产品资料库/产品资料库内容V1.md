# 模块 2 · 产品资料库 · 内容 V1（单一事实源）

> 母本：《门店销售三段论》（§5 包装五维：成分/人物/效果/信任/客户见证）
> 定位：底座 · 产品卖点/规格/常见问题/案例的统一知识源
> 📌 要点版，不写成段话术
> ⚠️ 资料源自门店（美业）语境，企业私域课使用须**脱敏 + 换语境**
> 📖 古文锚：一旦加入即固定，不可删

## 一、模块目标
建成企业产品的"单一事实源"——任何销售 / AI / 直播 / 朋友圈调用产品信息都从这里取，避免口径不一、随口编、各说各话。

## 二、为什么要建（三不治）
- 不治一：销冠凭记忆讲、新人讲错 → 统一口径
- 不治二：朋友圈 / 直播 / 话术各说各的 → 同源
- 不治三：客户问"和别家差在哪"答不上 → 见证据字段

## 三、产品资料库字段结构（五维落地）
1. **基础信息卡**
   - 品名 / 规格 / 价格 / 适用人群 / 不适用人群 / 交付形态
   - 一句话定位（电梯陈述）
2. **成分 / 工艺**（材料 + 制作流程）
   - 用料来源、关键工艺、耗时、独家点
3. **人物背书**
   - 谁研发 / 谁在用 / 谁推荐（创始人、专家、KOL，脱敏）
4. **效果证据**
   - 用了会怎样（场景化描述，非夸大）
   - 前后对比、数据指标
5. **信任资产**
   - 检测报告 / 认证 / 资质 / 媒体报道（脱敏）
   - 专业方案解答（FAQ）
6. **客户见证库**
   - 评价 / 对比 / 视频 / 权威推荐，按产品分桶
7. **常见问题 FAQ（异议预埋）**
   - 高频 20 问：价格 / 效果 / 安全 / 对比 / 售后

## 四、资料库使用规则
- 所有条目脱敏，禁出现"朱老师 / 门店 / 面膜"等原语境词
- 审核制：市场 + 产品双签入库存档，只增不删
- 与模块 1 方法库、模块 5 话术库同源调用

## 五、AI 结合点
- 结构化喂 AI，做"产品问答机器人"（内部销售顾问）
- 新人 / 客户问产品，AI 从资料库取证据作答，不瞎编
- 直播 / 朋友圈文案 AI 自动取卖点生成

> 📖 《礼记》"物有本末，事有终始"——先把产品这本源理清楚，销售才有始有终

## 六、常见坑
- 只写参数不写"用了会怎样" → 客户无感
- 见证用同行案例 → 优先自家脱敏真实案例
- 资料库成摆设不更新 → 设季度复核机制
