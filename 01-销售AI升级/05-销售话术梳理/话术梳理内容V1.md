## 一、模块目标
学员离课能交出一份自家产品的**销转话术手册**（≥20 条异议应答 + 成交路径图），且话术可机械套用、可 AI 批量生成。

## 二、话术的底层逻辑：微信成交四步
1. 自我介绍（破冰，立住人）
2. 需求诊断（发问，挖出真需求）
3. 塑造卖点（让他觉得相关 + 能解决）
4. 成交促单（临门一脚）
> 任何一句话术都落在这四步里，不乱。

## 三、客户对话三原则（防对抗）
- **共鸣原则**：先站客户立场，不反驳
- **请教原则**：把"推销"变成"请您指点"，降防御
- **专业原则**：用方案解答建立信任，不空谈
- 对话三大障碍：不了解产品 / 不自信 / 顾客怀疑——三原则逐一对症
- 📖 《论语》"工欲善其事，必先利其器"——话术是销售的器，先磨利

## 四、四类客户画像与应对
| 类型 | 特征 | 主攻话术 |
|---|---|---|
| 价格敏感型 | 一上来比价 | 价值体现法 / 重心转移法（对标） |
| 效果敏感型 | 怕没用 | 成分+见证+前后对比 |
| 从众敏感型 | 看别人买不买 | 客户见证 / 权威推荐 |
| 态度敏感型 | 怕被硬成交 | 淡化成交痕迹 / 共情 |

## 五、六种成交法（按场景选）
1. 直接成交法——信号明确时
2. 损失成交法——限时限量（制造错过）
3. 方案成交法——给定制方案替代逼单
4. 福利成交法——加赠不加价
5. 假设成交法——"您是付定金还是全款"（默认会买）
6. 感动成交法——服务细节打动

## 六、高频异议话术库（骨架，需填自家产品）
- **讲价**：换位思考法（"选择太多怕选错吧"）/ 价值体现法（工序/初心）/ 重心转移法（对标吃喝）/ 真诚发问法（"您顾虑是什么"）
- **排除对手**：攻破心理法（"您第一考虑的肯定不是价格"）/ 产品优势法（权威认证+创始人自用）
- **破解犹豫**：怕买错（共情+同类案例）/ 想要被重视（置顶+请教）/ 不想被成交（淡化痕迹，发问唤醒初心）/ 理由不到位（回扣最初动机）/ 后续麻烦（主动避坑显专业）
- **洞察客户**：以诚相待法 / 强化问题法 / 目标启发法 / 对话复盘法（"我确认下：您是因为XX要XX…"）
- **客户追销**：有意提醒（报你名优惠）/ 无意提醒（复购暗示+第三方启发）

## 七、话术库搭建方法（AI 辅助）
1. 收集销冠脱敏聊天记录 ≥20 段
2. AI 批量提取高频句 → 标注落在"四步"哪一步
3. 人工校准：共情→重构价值→证据→轻逼单 四步补全
4. 填模板（场景/客户原话/应答/成交后动作），每条四步齐全

## 八、常见坑
- 共情变认怂（"您说得对太贵了"）→ 共情是"理解顾虑"不是认贵
- 证据用同行案例 → 优先自家脱敏真实案例
- 硬催 → 假设成交法比硬逼单更稳
