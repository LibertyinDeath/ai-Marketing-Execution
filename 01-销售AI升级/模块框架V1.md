## 二、模块清单（分类 + 一句话定位）

### 底座（知识 / 资产）
1. **销售方法知识库** —— 打法 / SOP / 成交方法论沉淀，全课可调用
2. **产品资料库** —— 产品卖点 / 规格 / 常见问题 / 案例的统一知识源（宝总加）
3. **客户管理系统** —— 一套软件底座，管客户资产与分层标签

### 新客转化（流量接住 → 成交）
4. **新客承接系统** —— 加微首触 / 黄金 24h 动线，引流来的流量接得住
5. **销售话术梳理** —— 异议 / 成交话术结构化，销冠话术可复制
6. **一对一种草系统** —— 私聊阵地，单客信任培养
7. **朋友圈种草系统** —— 公开阵地，专业 / 生活 / 成交三线养信任
8. **群运营系统** —— 第三类阵地，群内激活 / 养熟 / 转化（宝总加）
9. **私域直播 / 发售系统** —— 集中转化大招，快闪群发售 / 直播成交

### 老客经营（复购）
10. **老客户激活系统** —— 沉睡客户唤醒
11. **老客户二转系统** —— 复购（二转 = 复购，宝总定）

### 团队人效（能力复制）
12. **AI 销售陪练** —— 用 AI 模拟难缠客户对练 + 上岗考核，新人即战力不拉低均值

### 过程治理（管动作 / 看数据 / 管团队）
13. **跟单过程系统** —— 跟进 SOP + AI 提醒 + 销售漏斗过程管理
14. **数据看板与周复盘系统** —— 转化漏斗数据 → 找最漏层 → 单变量实验（翻倍可测可守）
15. **销售目标与激励系统** —— 目标拆解到人到周 + 激励机制
16. **销售-交付交接系统** —— 销售承诺管理，防过度承诺退单
