# 模块 6 · 一对一种草系统 · 内容 V1（私聊信任培养）

> 母本：《门店销售三段论》（§3 发问技巧 / §4 小卡项设计 / §二 线下成交大卡体验前中后）

> 📌 要点版，不写成段话术
> ⚠️ 门店语境须脱敏换企业私域语境

## 一、模块目标
用私聊把"加微陌生客"养成熟人，靠发问 + 专业 + 节奏，自然走到成交。

## 二、一对一种草的本质
- 不是群发广告，是"一次只服务一个人"
- 信任 = 被懂 + 被帮（母本：销售是信任传递的过程）

## 三、私聊四步节奏（落成交四步）
1. **破冰**：诊断破冰 / 用途破冰（接模块 4）
2. **诊断**：发问五式层层进（母本§3 马斯洛五层）
   - 启发性 / 对比 / 过去 / 现在 / 未来式
3. **种草**：针对需求点给方案 + 见证（不报价）
4. **收口**：轻邀约（体验 / 直播 / 下单）

## 四、低成本钩子设计（母本§4 小卡项）
- 绝对不做免费，最好不赔本
- 周期 3 周 - 1 月、体验 ≥4 次，增加现场服务 + 决策人沟通
- 服务三阶段：体验前测评 / 体验中铺垫 / 体验后复查
- 前后两会：目标会 + 复盘会（接模块 14）

## 五、私聊节奏红线
- 不连发；间隔有理由（资料 / 提醒 / 案例）
- 不早报价；先诊断后方案
- 不硬成交；用假设成交法（接模块 5）

## 六、常见坑
- 把种草做成轰炸 → 被拉黑
- 诊断缺位直接推 → 不相关不买单
- 钩子免费 → 吸引羊毛党

## 七、AI 结合点
- AI 拟每次私聊话题（基于客户标签）
- 聊天记录自动提取需求点进客户档案（接模块 3）
- 对练练私聊节奏（接模块 12）
