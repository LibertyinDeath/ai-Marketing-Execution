## 〇、转化率翻倍 · 北极星目标定义

- **核心指标**：成交率（深聊客户 → 成交的比例）。引流课解决"来"，本课解决"成交"，翻倍必须落在成交率上才成立
- **全链路口径**：加微率 → 深聊率 → 成交率 三层同时盯，任一层塌了都谈不上翻倍
- **基线要求（入营第一周必做）**：学员先建数据看板、定自家基线成交率——**没有基线，不能喊翻倍**
- **翻倍拆解公式**：成交率 = 深聊客户数 × 单客成交概率
  - 不是靠"多聊"，是靠四件事：① 承接不掉人（保住深聊客分母）② 销冠话术复制（拉高单客成交概率）③ 新人即战力（不拉低均值）④ 数据迭代（守住并续涨）
- **四模块各攻一点**：
  - 模块 1（承接）→ 保住深聊客不漏（守分母）
  - 模块 2（销冠复制）→ 拉高单客成交概率（主引擎）
  - 模块 3（AI 助理）→ 保新人即战力、不拉低均值
  - 模块 4（数据迭代）→ 守成 + 持续涨（系统自转）
- **一句话给学员**：翻倍不是某个话术神了，是四个环节都做到位，体系自然翻倍

## 模块 1 · AI 私域承接：流量接得住（8 课时）

> 目标贡献：承接每漏 1 个深聊客，成交率分母就少 1。模块 1 确保加微 → 首聊 → 激活不掉链。

### 1.1 承接的本质
- 私域不是"多聊"，是"SOP 对"——承接决定深聊率，深聊率决定成交率分母
- 私域漏斗五段：加微 → 首聊 → 激活 → 朋友圈渗透 → 成交铺垫
- 漏点诊断：用看板看哪段掉人最多（多数企业死在"首聊后 48h 没动作"）
- 📖 《道德经》"合抱之木，生于毫末"——承接是毫末，漏了后面全白做

### 1.2 黄金 24 小时动线
- 加微后 **5 分钟内**首触（自动化打招呼 + 人工补一句个性化）
- 首聊三件事：确认需求场景 / 丢资料（价值锚）/ 打标签分层
- 24h 内二次触达节奏（首聊当晚 / 次日早）
- 模板：黄金 24h 动线图（时间轴 + 动作 + 话术触发点）

### 1.3 AI 话术库（三场景）
- 开场 / 激活 / 异议 三场景各 10 条 = **30 条话术库**
- 销冠话术结构化方法：挖出销冠的"破冰句 / 转折句 / 收口句"三件套
- AI 辅助：销冠聊天记录脱敏喂入 → AI 提取高频句 → 人工校准成库
- 信任红线：价格 / 投诉 / 情感类**必须人聊**，AI 只给建议不代发
- 模板：话术库 30 条表（场景 / 适用阶段 / 话术 / 禁用场景）

### 1.4 人设朋友圈三线
- 专业线（立信任）/ 生活线（拉近距离）/ 成交线（促单）比例建议 **5 : 3 : 2**
- 每天发什么、何时发（专业线早 / 生活线午 / 成交线晚）
- 发完怎么跟：成交线发布后 2h 内私信高意向客户
- 模板：朋友圈 30 天排期表

### 1.5 分层运营
- 按意向度 A / B / C 分层（A = 7 天内可成交，B = 培育，C = 长期）
- 各层触达节奏差异（A 每天轻触 / B 每周 2~3 次 / C 养着）
- AI 自动打标签 + 人工修正

**实操产出**：承接 SOP 动线图 + 话术库 V1（三场景各 10 条，共 30 条）

## 模块 2 · 销冠复制：话术炼金术（4 课时）【全课核心 · 直接攻成交率】

> 目标贡献：把销冠的成交概率复制到全员 → 单客成交概率拉高 → 成交率翻倍的主引擎。

### 2.1 成交三要素
- 动机 → 信任 → 临门一脚（缺一不可）
- **情感驱动优先于信息传递**（宝总方法论：先动情再讲理）
- 极端观点开头切入（钩子）→ 情感共鸣 → 方案
- 📖 《传习录》"知是行之始，行是知之成"——懂成交逻辑，才能复制成交

### 2.2 销冠复盘法
- 提取自家脱敏成交聊天记录（≥ 20 段）
- AI 批量分析：找成交路径共性（第几轮提价、什么异议后成交）
- 输出成交路径图（标准动线）
- 模板：成交路径提取提示词（喂记录 → 出路径）

### 2.3 高频异议库（四类全覆盖）
- 价格 / 拖延 / 比价 / 家人反对 四类
- 每类应答体系：**共情 → 重构价值 → 证据 → 轻逼单**
- 目标 **≥ 20 条**（每类 5 条）
- 模板：异议应答手册（异议类型 / 客户原话 / 应答话术 / 成交后动作）

### 2.4 朋友圈成交线
- 发什么（客户案例 / 前后对比）、何时发（晚 8~10 点）、发完怎么跟
- 成交线不是硬广，是"别人已经买了"的社会证明

**实操产出**：销转话术手册 V1（成交路径图 + ≥ 20 条异议应答）——本模块留足实操时间

## 模块 3 · AI 销售助理：跟单不靠自觉（4 课时）

> 目标贡献：新人上岗即对练达标，不拉低团队成交率均值（保住模块 2 复制的成果）。

### 3.1 AI 对练系统
- 用 AI 扮演"难缠客户"训练新人（价格敏感 / 反复拖延 / 比价型）
- 提示词设计：角色设定 + 客户画像 + 刁难脚本 + 评分维度
- 现场教写提示词
- 模板：对练提示词模板（角色 / 场景 / 刁难点 / 评分表）

### 3.2 对练考核
- 新人上岗前必须过对练（3 类客户各一轮，评分 ≥ 80）
- 考核不通过不准独立跟单
- 📖 《论语》"工欲善其事，必先利其器"——AI 对练是新人上岗的利器

### 3.3 跟单 AI
- 跟进提醒（到期自动提醒，不靠自觉）
- 客户画像小结（AI 读聊天记录出小结）
- 话术建议（下一步发什么）
- 工具形态：企微 + AI 插件 / WorkBuddy 类助理

### 3.4 合规红线
- 企微风控边界（频繁加人 / 群发限流）
- 必须人聊场景（投诉 / 退款 / 大额）
- AI 出错兜底（人工复核机制）
- 不出事故，翻倍才有效

**实操产出**：AI 对练提示词模板 + 跟单 SOP

## 模块 4 · 转化数据看板与迭代（陪跑 8 课时）

> 目标贡献：守住翻倍成果并持续涨——从"我盯"到"系统自转"。

### 4.1 看板搭建
- 三层漏斗：加微率 / 深聊率 / 成交率（表格起步够用）
- 每人 / 每渠道分开看，找最差环节
- 模板：转化看板（日期 / 渠道 / 加微 / 深聊 / 成交 / 各率）

### 4.2 AI 诊断
- 喂数据 → AI 找最漏人的一层 → 给改进假设
- 提示词：上传周数据 → 输出"最该改的 1 个环节 + 假设"
- 📖 《道德经》"天下难事，必作于易"——先改最漏的那一层

### 4.3 单变量实验
- 一次只改一个变量（话术 / 内容 / 动线）
- 两周一实验，对比前后成交率
- 防坑：别同时改多个变量，否则说不清哪有效

### 4.4 周复盘固化
- 谁（销售主管）、何时（周一）、看什么（看板）、改什么（实验结论）
- 闭环：数据 → 诊断 → 实验 → 复盘 → 再数据
- 目标：结营时成交率 ≥ 基线 2 倍，且机制能自转

**实操产出**：转化看板 V1 + 周复盘记录 + 1 个被数据验证的迭代动作

## 转化率翻倍 · 结营验收口径

- **验收公式**：结营成交率 ÷ 入营基线成交率 **≥ 2**
- **三产出齐全**：承接 SOP / 销转话术手册 / AI 对练提示词 + 跟单 SOP
- **对练通过**：新人全部过对练考核
- **看板跑通**：结营前一周看板有真实数据、有 1 次单变量实验记录
- **路演**：拿前后 30 天数据对比，师团评"真翻倍"案例
- ⚠️ 翻倍是**体系结果**不是单点技巧——四模块缺一无翻倍
