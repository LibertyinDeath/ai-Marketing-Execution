## 〇、转化率翻倍 · 北极星目标定义

- **核心指标**：成交率（深聊客户 → 成交的比例）。引流课解决"来"，本课解决"成交"，翻倍必须落在成交率上才成立
- **全链路口径**：加微率 → 深聊率 → 成交率 三层同时盯，任一层塌了都谈不上翻倍
- **基线要求（入营第一周必做）**：学员先建数据看板、定自家基线成交率——**没有基线，不能喊翻倍**
- **翻倍拆解公式**：成交率 = 深聊客户数 × 单客成交概率
  - 不是靠"多聊"，是靠四件事：① 承接不掉人（保住深聊客分母）② 销冠话术复制（拉高单客成交概率）③ 新人即战力（不拉低均值）④ 数据迭代（守住并续涨）
- **四模块各攻一点**：
  - 模块 1（承接）→ 保住深聊客不漏（守分母）
  - 模块 2（销冠复制）→ 拉高单客成交概率（主引擎）
  - 模块 3（AI 助理）→ 保新人即战力、不拉低均值
  - 模块 4（数据迭代）→ 守成 + 持续涨（系统自转）
- **一句话给学员**：翻倍不是某个话术神了，是四个环节都做到位，体系自然翻倍

## 模块 1 · AI 私域承接：流量接得住（8 课时 · D1 全天）

> 目标贡献：承接每漏 1 个深聊客，成交率分母就少 1。模块 1 确保加微 → 首聊 → 激活不掉链。
> 时段：D1 上午 4h（1.1~1.2）+ D1 下午 4h（1.3~1.5 + 验收）
> 节奏铁律：每半天讲授 ≤40% / 演示 20% / 实操 ≥30% / 点评 10%

### 1.1 承接的本质（40min）
- **知识点颗粒**：
  1. 私域 ≠ 多聊，是 SOP 对——承接质量决定深聊率
  2. 私域漏斗五段：加微 → 首聊 → 激活 → 朋友圈渗透 → 成交铺垫
  3. 漏点定位法：哪段掉人最多，哪段就是翻倍的第一杠杆
  4. 数据真相：多数企业死在"首聊后 48h 没动作"
- **讲师讲授要点**：用 1 个真实脱敏案例，画出自家漏斗五段，标出当前掉人最多的那段
- **演示（20%）**：现场在白板/表格画一个"漏得厉害"的漏斗，标注掉人率
- **学员实操（≥30%）**：每人画出自家产品当前私域漏斗五段，圈出最漏的一段（交「漏斗现状图」）
- **常见坑/纠偏**：学员常说"我们聊得挺多"→ 纠：聊得多不等于接得住，看深聊率而非聊天条数
- **📖 古文锚**：《道德经》"合抱之木，生于毫末"——承接是毫末，漏了后面全白做
- **本小节检查点**：每人漏斗现状图上有且仅有 1 个标红的最漏段

### 1.2 黄金 24 小时动线（60min）
- **知识点颗粒**：
  1. 加微后 5 分钟内首触（自动打招呼 + 人工一句个性化）
  2. 首聊三件事：确认需求场景 / 丢资料（价值锚）/ 打标签分层
  3. 24h 内二次触达节奏（首聊当晚 + 次日早）
  4. 动线图三要素：时间轴 + 动作 + 话术触发点
  5. 为什么是 24h：错过黄金窗口，深聊率断崖下跌
- **讲师讲授要点**：讲清"5 分钟 / 当晚 / 次日早"三个触点的心理逻辑（趁热打铁）
- **演示（20%）**：讲师展示一条真实流量的 24h 动线截图（脱敏），逐点击破
- **学员实操（≥30%）**：用模板 A 画出自家黄金 24h 动线图（时间轴 + 动作 + 话术触发点）
- **常见坑/纠偏**：把"自动打招呼"当"首聊"→ 纠：自动打招呼只是开门，人工个性化那一句才是首聊
- **本小节检查点**：动线图含 3 个明确触点 + 每触点有话术触发点

### 1.3 AI 话术库 · 三场景（120min · 核心产出）
- **知识点颗粒**：
  1. 三场景划分：开场 / 激活 / 异议，各 10 条 = 30 条话术库
  2. 销冠话术结构化三件套：破冰句 / 转折句 / 收口句
  3. AI 提取法：销冠聊天记录脱敏 → 喂入 AI → 提取高频句 → 人工校准
  4. 话术库字段：场景 / 适用阶段 / 话术 / 禁用场景
  5. 信任红线：价格 / 投诉 / 情感类必须人聊，AI 只给建议不代发
  6. 话术不是背，是"结构化后可组合"
- **讲师讲授要点**：现场拆 1 条销冠真实话术，指出它的破冰/转折/收口三段分别在哪
- **演示（20%）**：讲师用脱敏销冠记录现场跑 AI 提取提示词，产出 5 条候选话术，人工校准成库
- **学员实操（≥30%）**：
  - 分组（每企业 2~3 人）从自带脱敏记录里挑 3 段成交对话
  - 跑 AI 提取 → 每组产出三场景话术各 ≥5 条（先达 15 条，课后补满 30 条）
  - 填模板 B（话术库 30 条表骨架，本小节先填 15 条）
- **常见坑/纠偏**：
  - 直接让 AI 编话术 → 纠：必须基于自家真实记录，AI 只做提取不选编
  - 把"禁用场景"留空 → 纠：每条必须标清什么情况不能发这句
- **本小节检查点**：每组模板 B 至少 15 条，且每条有"禁用场景"字段

### 1.4 人设朋友圈三线（60min）
- **知识点颗粒**：
  1. 三线结构：专业线（立信任）/ 生活线（拉近距离）/ 成交线（促单）
  2. 比例建议 5 : 3 : 2
  3. 发布时间：专业线早 / 生活线午 / 成交线晚
  4. 成交线发布后 2h 内私信高意向客户（朋友圈 → 私聊的跳转）
  5. 朋友圈是"养信任"，不是发广告
- **讲师讲授要点**：展示一个脱敏账号 30 天朋友圈节奏，讲清三线如何交替不违和
- **演示（20%）**：讲师现场排未来 3 天三线内容（口头 + 表格）
- **学员实操（≥30%）**：用模板填自家朋友圈 30 天排期表（至少排满首周 7 天，三线比例合规）
- **常见坑/纠偏**：成交线发成硬广 → 纠：成交线=客户案例/前后对比的社会证明，不是"快来买"
- **本小节检查点**：排期表首周 7 天填满，专业:生活:成交 ≈ 5:3:2

### 1.5 分层运营（40min）
- **知识点颗粒**：
  1. A/B/C 分层：A=7 天内可成交 / B=培育 / C=长期
  2. 各层触达节奏：A 每天轻触 / B 每周 2~3 次 / C 养着
  3. AI 自动打标签 + 人工修正（标签是分层依据）
  4. 分层目的：把有限精力压在 A 上，保住成交率分母里的高意向客
- **讲师讲授要点**：讲清"为什么不能对所有客户一视同仁"——精力错配是深聊率漏点的第二大原因
- **演示（20%）**：讲师展示标签体系 + 一层客户的实际触达记录
- **学员实操（≥30%）**：在承接 SOP 动线图上补"分层触达节奏"一栏（A/B/C 各写节奏）
- **常见坑/纠偏**：C 层完全不理 → 纠：C 要养，但低频，别零触达导致遗忘
- **本小节检查点**：SOP 动线图有 A/B/C 三层触达节奏标注

### 1.6 模块 1 现场验收（40min）
- **验收动作**：讲师 + 助教逐组查两份产出——承接 SOP 动线图（含 24h 触点 + 分层节奏）+ 话术库 V1（≥15 条，当场要求补满 30 条计划）
- **打回标准**：动线无 3 触点 / 话术无禁用场景 / 漏斗无标红段 → 当场重做
- **模块 1 出口标准**：两份产出齐全且过验收，方可进模块 2

**模块 1 实操总产出**：承接 SOP 动线图 + 话术库 V1（三场景各 10 条，共 30 条）

## 模块 2 · 销冠复制：话术炼金术（4 课时 · D2 上午）【全课核心 · 直接攻成交率】

> 目标贡献：把销冠的成交概率复制到全员 → 单客成交概率拉高 → 成交率翻倍的主引擎。
> 时段：D2 上午 4h（2.1~2.4 + 验收）

### 2.1 成交三要素（40min）
- **知识点颗粒**：
  1. 成交 = 动机 → 信任 → 临门一脚（缺一不可，顺序不能乱）
  2. 情感驱动优先于信息传递（宝总方法论：先动情再讲理）
  3. 极端观点开头切入（钩子）→ 情感共鸣 → 方案
  4. 三要素自查：客户没动，是缺动机 / 缺信任 / 还是缺临门一脚？
- **讲师讲授要点**：用 1 段脱敏成交录音拆"动机/信任/临门一脚"分别发生在第几分钟
- **演示（20%）**：讲师现场重演一段"先用极端观点破冰、再给情感共鸣"的开场
- **学员实操（≥30%）**：每人从自带记录里标出 1 个成交案例中三要素各自的位置
- **常见坑/纠偏**：一上来就讲产品参数 → 纠：没动机没信任，参数等于零
- **📖 古文锚**：《传习录》"知是行之始，行是知之成"——懂成交逻辑，才能复制成交
- **本小节检查点**：每人能说出"我家客户卡在三要素哪一环最多"

### 2.2 销冠复盘法（50min）
- **知识点颗粒**：
  1. 提取素材：自家脱敏成交聊天记录 ≥ 20 段
  2. AI 批量分析法：找成交路径共性（第几轮提价 / 什么异议后成交）
  3. 成交路径图 = 标准动线（可复制的动作序列）
  4. 人工校准：AI 给的是"共性候选"，销冠判断哪些值得固化
  5. 复盘频率：新销冠记录进来就复，不是季度才复
- **讲师讲授要点**：讲清"为什么用 AI 批量而不是靠销冠口述"——口述会美化，记录不会
- **演示（20%）**：讲师现场用 ≥20 段脱敏记录跑 AI 批量分析提示词，出成交路径图
- **学员实操（≥30%）**：每组用自带记录跑 AI 批量分析，产出 1 张"成交路径图"（标准动线）
- **常见坑/纠偏**：
  - 记录太少（<20 段）→ 纠：样本不够共性不准，先凑够 20 段
  - 直接信 AI 结论 → 纠：AI 出候选，销冠拍板固化哪几步
- **本小节检查点**：每组有 1 张成交路径图，标注"必做动作序列"

### 2.3 高频异议库 · 四类全覆盖（90min · 核心产出）
- **知识点颗粒**：
  1. 四类高频异议：价格 / 拖延 / 比价 / 家人反对
  2. 每类应答体系：**共情 → 重构价值 → 证据 → 轻逼单**（四步固定结构）
  3. 目标 ≥ 20 条（每类 ≥5 条）
  4. 异议库字段：异议类型 / 客户原话 / 应答话术 / 成交后动作
  5. 证据从哪来：自家客户案例 / 前后对比 / 数据
  6. "轻逼单"不是硬催，是给一个低门槛的下一步动作
- **讲师讲授要点**：现场拆 1 条"价格异议"，走完共情→重构→证据→轻逼单四步
- **演示（20%）**：讲师用 AI 把 1 类异议的 5 条候选应答一次性生成，小组校准
- **学员实操（≥30%）**：
  - 每组认领 1~2 类异议，用 AI 生成候选 + 人工校准，写出该类 ≥5 条
  - 全组合并成模板 C（异议应答手册），本小节凑满 ≥20 条
  - 每条走完四步结构、且"成交后动作"非空
- **常见坑/纠偏**：
  - 共情变成认怂（"您说得对太贵了"）→ 纠：共情是"我理解您的顾虑"，不是同意贵
  - 证据用同行案例 → 纠：优先用自家脱敏真实案例，可信度高
- **本小节检查点**：模板 C 四类齐全、≥20 条、每条四步结构完整

### 2.4 朋友圈成交线（30min）
- **知识点颗粒**：
  1. 发什么：客户案例 / 前后对比（社会证明）
  2. 何时发：晚 8~10 点（客户放松刷手机）
  3. 发完怎么跟：2h 内私信高意向 A 层客户"看到那条没，您这情况其实…"
  4. 成交线是把朋友圈流量导回私聊的钩子
- **讲师讲授要点**：讲清"朋友圈成交线 → 私聊临门一脚"的衔接
- **演示（20%）**：讲师展示 1 条成交线发布后，如何私信 3 个 A 层客户
- **学员实操（≥30%）**：在模板 C 补"成交线发布后跟进口径"一栏
- **常见坑/纠偏**：发完不跟 → 纠：成交线不发完就废一半，必须 2h 内跟
- **本小节检查点**：模板 C 有成交线跟进口径

### 2.5 模块 2 现场验收（30min）
- **验收动作**：讲师 + 助教逐组查销转话术手册 V1（成交路径图 + 异议手册 ≥20 条）
- **打回标准**：异议 <20 条 / 四步结构缺环 / 成交后动作空 → 当场补
- **模块 2 出口标准**：手册齐全过验收，且每组能口述"我家成交靠哪条路径"

**模块 2 实操总产出**：销转话术手册 V1（成交路径图 + ≥20 条异议应答）——本模块是全课核心，留足实操

## 模块 3 · AI 销售助理：跟单不靠自觉（4 课时 · D2 下午）

> 目标贡献：新人上岗即对练达标，不拉低团队成交率均值（保住模块 2 复制的成果）。
> 时段：D2 下午 4h（3.1~3.4）

### 3.1 AI 对练系统（70min）
- **知识点颗粒**：
  1. 用 AI 扮演"难缠客户"训练新人（价格敏感 / 反复拖延 / 比价型三类）
  2. 对练提示词四要素：角色设定 + 客户画像 + 刁难脚本 + 评分维度
  3. 评分维度示例：共情到位 / 价值重构准 / 证据恰当 / 逼单适度
  4. 对练不是考试，是"安全地练砸"——练完 AI 给改进点
  5. 提示词可复用：一套角色模板，换画像即可练不同客户
- **讲师讲授要点**：讲清"为什么新人要先对练再上岗"——真实客户不是练习场
- **演示（20%）**：讲师现场跑 1 个"价格敏感型"对练，展示 AI 如何给评分和改进点
- **学员实操（≥30%）**：每组现场写 1 类客户的对练提示词（角色/画像/刁难/评分），跑通 1 轮
- **常见坑/纠偏**：
  - 提示词不写评分维度 → 纠：没评分新人不知道练得咋样
  - 刁难脚本太弱 → 纠：要对标真实最难缠的客户，别放水
- **📖 古文锚**：《论语》"工欲善其事，必先利其器"——AI 对练是新人上岗的利器
- **本小节检查点**：每组有 1 份可运行的对练提示词（四要素齐全）

### 3.2 对练考核（40min）
- **知识点颗粒**：
  1. 上岗前必过对练：3 类客户各一轮，评分 ≥ 80
  2. 不通过不准独立跟单（保护成交率均值）
  3. 考核记录入档，作为新人胜任证据
  4. 老销冠也过一遍 → 校准"80 分"的基准线
- **讲师讲授要点**：讲清"80 分线"定在哪——基于真实销冠对练均分
- **演示（20%）**：讲师用 1 名学员试跑完整考核（三类各一轮）
- **学员实操（≥30%）**：现场两两互考，至少每人跑完 1 类客户对练并打分
- **常见坑/纠偏**：老销冠免考 → 纠：老销冠也要跑，否则 80 分基准无依据
- **本小节检查点**：有对练评分表模板 + 至少 1 人完整跑完一类

### 3.3 跟单 AI（50min）
- **知识点颗粒**：
  1. 跟进提醒：到期自动提醒，不靠自觉
  2. 客户画像小结：AI 读聊天记录出小结（谁/卡哪/下一步）
  3. 话术建议：下一步发什么（调模板 B/C）
  4. 工具形态：企微 + AI 插件 / WorkBuddy 类助理
  5. 跟单 AI 是"外脑"，最终话术人发、人负责
- **讲师讲授要点**：讲清"跟单 AI 解决的是遗忘和偷懒，不是替代销售"
- **演示（20%）**：讲师演示一条客户从加微到成交的 AI 跟单提醒流
- **学员实操（≥30%）**：每人配置 1 条自己产品的跟单提醒规则（触发条件 + 提醒内容）
- **常见坑/纠偏**：AI 自动发话术 → 纠：提醒可以自动，发送必须人点
- **本小节检查点**：每人有 1 条可运行的跟单提醒规则

### 3.4 合规红线（40min）
- **知识点颗粒**：
  1. 企微风控边界：频繁加人 / 群发限流（账号封禁风险）
  2. 必须人聊场景：投诉 / 退款 / 大额（AI 不代处理）
  3. AI 出错兜底：人工复核机制（发出前过一眼）
  4. 不出事故，翻倍才有效——事故一次清零信任
- **讲师讲授要点**：用 1 个真实封号/投诉案例讲"红线踩不得"
- **演示（20%）**：展示"AI 建议 → 人复核 → 人发送"的正确链路截图
- **学员实操（≥30%）**：在跟单 SOP 里补"必须人聊场景清单"一栏
- **常见坑/纠偏**：为省事全托 AI → 纠：红线场景零容忍，写进 SOP 并签字
- **本小节检查点**：跟单 SOP 含"必须人聊场景清单"

### 3.5 模块 3 现场验收（20min）
- **验收动作**：查两份产出——AI 对练提示词模板（四要素齐）+ 跟单 SOP（含人聊清单）
- **打回标准**：提示词无评分维度 / SOP 无人聊清单 → 补
- **模块 3 出口标准**：两份产出齐全，且至少 1 人跑通对练

**模块 3 实操总产出**：AI 对练提示词模板 + 跟单 SOP

## 模块 4 · 转化数据看板与迭代（陪跑 8 课时 · 4 周直播各 2h）

> 目标贡献：守住翻倍成果并持续涨——从"我盯"到"系统自转"。
> 时段：Week1~4 每周一直播 2h + 群内作业逐份点评（点评即二次教学）

### 4.1 看板搭建（Week1 直播 2h）
- **知识点颗粒**：
  1. 三层漏斗：加微率 / 深聊率 / 成交率（表格起步够用，别一上来上 BI）
  2. 每人 / 每渠道分开看，找最差环节
  3. 看板字段：日期 / 渠道 / 加微 / 深聊 / 成交 / 各率
  4. 基线锁定：Week1 交的看板 = 翻倍公式的分母基准
- **讲师讲授要点**：讲清"为什么表格就够"——过早上工具反而没人填
- **演示（20%）**：讲师展示一个真实企业周看板，指出最差环节
- **学员实操（≥30%）**：交看板 V1（自家近 2 周真实数据，锁定基线成交率）
- **常见坑/纠偏**：渠道混填 → 纠：不分渠道看不出哪条线漏
- **📖 古文锚**：《道德经》"天下难事，必作于易"——先改最漏的那一层
- **本小节检查点**：看板 V1 有分渠道数据 + 标出基线成交率

### 4.2 AI 诊断（Week2 直播 2h）
- **知识点颗粒**：
  1. 喂数据 → AI 找最漏人的一层 → 给改进假设
  2. 诊断提示词：上传周数据 → 输出"最该改的 1 个环节 + 假设"
  3. 诊断结论要可验证，不是"感觉"
  4. 与对练考核周复盘会 1 合并进行
- **讲师讲授要点**：讲清"诊断只给 1 个最该改的环节"——同时改多个等于没改
- **演示（20%）**：讲师现场喂一组周数据，跑 AI 诊断出"最漏层 + 假设"
- **学员实操（≥30%）**：每人用自家 Week1 看板跑 AI 诊断，写出"最漏层 + 1 个改进假设"
- **常见坑/纠偏**：AI 给一堆建议都改 → 纠：只取最漏的那一层
- **本小节检查点**：每人有"最漏层 + 假设"结论

### 4.3 单变量实验（Week3 直播 2h）
- **知识点颗粒**：
  1. 一次只改一个变量（话术 / 内容 / 动线）
  2. 两周一实验，对比前后成交率
  3. 防坑：别同时改多个变量，否则说不清哪有效
  4. 实验设计：假设 → 改 1 样 → 测 2 周 → 比成交率
- **讲师讲授要点**：讲清"单变量"是科学迭代的底线
- **演示（20%）**：讲师展示 1 个真实实验（只改首聊话术，成交率从 X 到 Y）
- **学员实操（≥30%）**：每人定 1 个单变量实验（基于 4.2 假设），启动执行
- **常见坑/纠偏**：改话术又改节奏 → 纠：变量只能 1 个
- **本小节检查点**：每人有 1 份单变量实验设计（假设 + 唯一变量 + 周期）

### 4.4 周复盘固化（Week4 直播 2h + 结营路演）
- **知识点颗粒**：
  1. 谁（销售主管）、何时（周一）、看什么（看板）、改什么（实验结论）
  2. 闭环：数据 → 诊断 → 实验 → 复盘 → 再数据
  3. 目标：结营时成交率 ≥ 基线 2 倍，且机制能自转
  4. 结营路演：前后 30 天数据对比，师团评"真翻倍"案例
- **讲师讲授要点**：讲清"复盘会不是汇报，是定下周改什么"
- **演示（20%）**：讲师展示一个"从周复盘长出的迭代动作"真实案例
- **学员实操（≥30%）**：交周复盘记录 + 结营路演（数据前后对比）
- **常见坑/纠偏**：复盘会成批斗会 → 纠：对事不对人，看数据不看态度
- **本小节检查点**：周复盘记录 + 路演材料（基线 vs 结营成交率）

### 4.5 模块 4 出口标准
- 看板 V1 跑通 + 1 次单变量实验有结论 + 周复盘记录 + 路演完成

**模块 4 实操总产出**：转化看板 V1 + 周复盘记录 + 1 个被数据验证的迭代动作

## 转化率翻倍 · 结营验收口径

- **验收公式**：结营成交率 ÷ 入营基线成交率 **≥ 2**
- **三产出齐全**：承接 SOP / 销转话术手册 / AI 对练提示词 + 跟单 SOP
- **对练通过**：新人全部过对练考核
- **看板跑通**：结营前一周看板有真实数据、有 1 次单变量实验记录
- **路演**：拿前后 30 天数据对比，师团评"真翻倍"案例
- ⚠️ 翻倍是**体系结果**不是单点技巧——四模块缺一无翻倍
