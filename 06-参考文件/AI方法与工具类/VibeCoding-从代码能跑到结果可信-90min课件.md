## 第 8 页 · 把模糊话翻译成六格规格

02 / 定义意图

00:14 — 00:16

将含糊话翻译为六格工程规格 (6-Box Spec)

规格不是形式主义文档，而是人机协同中唯一具有约束力的防漂移契约。

01 / GOAL (目标)

计算 A、B 组受试者在 Day0 与 Day7 的个体配对提升幅度 均值。

02 / INPUT (输入)

仅读取 raw/scores.csv ；固定字段：sample, group, day0, day7。

03 / INVARIANT (不变式)

仅允许 同一 sample 的前后测相减 ；禁止全组跨样本独立聚合。

04 / EXCEPTION (异常)

遇到 NA 严禁补 0 ；记录并剔除单侧缺失，独立输出缺失名单。

05 / OUTPUT (产物)

严格输出 results/summary.csv 与 results/change.svg 。

06 / ACCEPT (验收)

断言： A = +5.0, B = +10.0, 剔除数 = 1 ；单元测试全绿。

规格说明书是人与模型之间唯一不可妥协的真理基准。 SPEC DRIVEN

NON-GOALS / 明确列出“禁止事项”

禁止联网调用任何外部未授权 API。

禁止引入除 Python 标准库及原生 Pandas/Matplotlib 外的新依赖。

严禁改写或删除 raw/ 目录下的任何原始实验文件。

禁止擅自更改输出路径与表头字段命名格式。

禁止将样本层面的描述性均值差异包装为因果证明。

对于研一科研课题，一份 8 行规格足以消除 90% 的低级翻车事故。

目标、输入、不变式、异常、产物、验收——在生成代码前永远先写满这六格。
